# 5. 最长回文子串 (Longest Palindromic Substring)

> 难度：**中等**  |  分组：多维动态规划  |  链接：https://leetcode.cn/problems/longest-palindromic-substring/

> 标签：双指针, 字符串, 动态规划, Manacher 算法


## 题目

给你一个字符串 `s`，找到 `s` 中最长的 回文 子串。

 

示例 1：

```

输入：s = "babad"
输出："bab"
解释："aba" 同样是符合题意的答案。

```

示例 2：

```

输入：s = "cbbd"
输出："bb"

```

 

提示：

	
- `1 <= s.length <= 1000`
	
- `s` 仅由数字和英文字母组成
